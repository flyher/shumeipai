# 树莓派文档归档


## 阅读入口

- [在线阅读](https://flyher.github.io/shumeipai/)

这是一个 Raspberry Pi 资料归档项目，共收录 113 篇文章。

项目在保留原始网页的同时，提供重新排版的整理版，并尽可能将文章引用的图片和必要附件保存在仓库中。

> 但是这些文章大多整理于 2014 年前后，部分命令、软件版本和下载地址可能已经失效，连当初援引的站点也不复存在了。不管怎么样，趁着 2026年 AI Coding 的流行，用 codex 批量整理了剩下的 markdown 页面，也算是为当年的树莓派收了尾吧。

![logo.jpg](./logo.jpg)


## 版本说明

- **整理版**：按照目录序号重新排版，尽可能使用本地资源，适合直接阅读。
- **原始页**：保留归档时的 HTML 页面，用于核对原文和旧版页面结构。

每篇整理版文章顶部提供“返回文档目录”和“查看原始页”入口。没有对应原始页面时，会显示“原始页缺失”。

## 目录说明

- `md/`：整理版文章，文件名以文章序号开头。
- `content/`：原始 HTML 页面。
- `src/`：文章引用的本地图片和附件，按文章序号分目录保存。
- `js/`：整理版页面使用的本地脚本和样式。
- `pdf/`：历史 PDF 资料。
- `tools/`：文档迁移和资源整理脚本。
